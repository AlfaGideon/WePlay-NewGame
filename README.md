# Карточный Советник — APK-виджет для «Карточный магнат» (WePlay)

Плавающий Android-виджет поверх игры **«Карточный магнат» (WePlay)** с **обновлением по воздуху (OTA) без секретных ключей**, автоматическим считыванием экрана и многоходовым просчётом ходов.

---

## Что нового в v1.1

- **Обновление по воздуху (OTA) без секретных ключей**:
  - Все сборки подписываются единым универсальным ключом (`app/signing/universal-ota.p12`), поэтому новые версии устанавливаются прямо поверх старой без удаления приложения и без потери настроек.
  - Приложение само проверяет публичный GitHub Releases API (`AlfaGideon/WePlay-NewGame/releases/latest`), скачивает свежий APK и запускает установщик. Настраивать секреты в GitHub не требуется.
- **Фиксация рекомендаций строго на вашем ходу (Turn-Lock + консенсус 2 кадров)**:
  - Во время ходов других игроков рекомендации **не прыгают** — виджет тихо следит за изменениями на поле и ждёт ваш ход.
  - Когда загораются ваши карты, алгоритм подтверждает их по 2 кадрам и **фиксирует один стабильный совет** строго из реально имеющихся у вас карт.
- **Точное позиционирование оверлея**:
  - Исправлен сдвиг подсветки карт и клеток из-за выреза камеры / статус-бара (`DisplayCutout` + `getLocationOnScreen`).
- **Обновлённый OCR карт**:
  - Выделение сплошной внутренней заливки цифр (`saturation + luminance + 3x3 фильтр`) исключает «пустые контуры» и ложные цифры.
- **Актуальные правила игры**:
  - Розовый барабан: **x1–x4** (макс. x4).
  - Ловушка **Бомба**: взрыв → больница на 2 хода.
  - Ловушка **Какашка**: подскальзывание → потеря денег.
  - **Фиолетовый мешок «?»**: учитывает риск выпадения ловушек.

## Установка и OTA-обновление

1. Скачайте последний релиз **`CardTycoonHelper-v1.1.X.apk`** со страницы [GitHub Releases](https://github.com/AlfaGideon/WePlay-NewGame/releases/latest) (или из артефактов [GitHub Actions](https://github.com/AlfaGideon/WePlay-NewGame/actions)).
2. Если раньше стояла тестовая сборка `debug` (v1.0.0) со случайной подписью — удалите её один раз и установите `v1.1.X` с универсальной подписью.
3. Все последующие обновления будут прилетать прямо внутри приложения по кнопке **«Проверить обновления (OTA)»**!
