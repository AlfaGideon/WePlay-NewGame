# Карточный Советник — APK-виджет для «Карточный магнат» (WePlay)

Плавающий Android-виджет поверх игры **«Карточный магнат» (WePlay)**, который автоматически считывает экран в реальном времени через `MediaProjection` + локальный OCR (ML Kit), анализирует позиции всех игроков, дома, аренды и спецклетки, и **подсвечивает самый выгодный ход прямо поверх ваших 4 карт внизу экрана**.

---

## Возможности

- **Автоматическое чтение экрана (без root и без вмешательства в клиент игры)**:
  - Автокалибровка 28-клеточного изометрического поля по ориентирам `GO` и `НЛО` — работает на любых разрешениях экрана.
  - Распознавание позиций всех 4 фишек игроков, владельцев 20 территорий (даже если фишка стоит прямо на чужом доме), ловушек (грязь), банкротства, баланса наличных, раунда (`XX / 30`), прогресса молоточков (`0..4`) и 1–4 карт в руке (`+` зелёные вперёд и `-` отрицательные назад).
  - Временное сглаживание (`BoardStateTracker`), чтобы всплывающие надписи (`+100`) и анимации прыжков не сбивали распознанное состояние.
- **Умный многоходовый просчёт (`StrategyEngine`)**:
  - Учитывает движение **против часовой стрелки** (`+`) и назад по часовой (`-`) по 28 клеткам.
  - Перебирает **все комбинации оставшихся карт в руке** (до `4! = 24` последовательностей) — находит цепочки ходов на 2–4 раунда вперёд (например, `GO → Мечи → НЛО → свободная клетка за 400`).
  - Учитывает **4 деления молоточка** (бонус за завершение `4/4` и кратный рост дохода со всех территорий).
  - Оценивает угрозы от позиций соперников, держит запас кеша от банкротства и перестраивается под эндшпиль ближе к 30-му раунду.
  - Даёт конкретные тактические подсказки по всем спецклеткам:
    - **НЛО (кл. 14)** — рассчитывает, на какую именно свободную (или самую дешёвую) клетку телепортироваться, и подсвечивает её на поле.
    - **Кошелёк (кл. 11)** — подсказывает, у кого выгоднее красть.
    - **Мечи (кл. 7)** — рассчитывает, с кем выгоднее заключить **Дуэль (x2)**, а с кем **Союз (50/50)**.
    - **Розовая клетка (кл. 21 — Барабан x1–x10)** — динамически оценивает выгоду от текущего суммарного дохода ваших территорий.
    - **Жёлтые «?» (кл. 4, 24)** и **Фиолетовый мешок (кл. 18)** — настраиваемые веса в приложении.
- **Удобный плавающий интерфейс**:
  - Подсветка лучшей карты (`★ ЛУЧШИЙ`) и опасных карт (`⚠ РИСК`) сквозным неблокирующим слоем прямо поверх игры (нажатия проходят напрямую в игру!).
  - Компактный сворачиваемый режим «пилюли» + развёрнутая карточка с планом руки и ручной коррекцией цифры карты в 1 тап.

## Как получить готовый `.apk`

### Способ 1: Скачать собранный APK из GitHub Actions (самый простой)
1. Откройте вкладку **Actions** в репозитории GitHub → выберите последний успешный запуск **Build Android APK**.
2. В разделе **Artifacts** скачайте **`CardTycoonHelper-APK`** (`CardTycoonHelper-debug.apk`).
3. Установите APK на Android-смартфон (Android 8.0 / API 26 и выше).

### Способ 2: Собрать локально
Требуется JDK 17 и Android SDK (API 34):
```bash
gradle testDebugUnitTest assembleDebug
```
Готовый файл появится по пути `app/build/outputs/apk/debug/app-debug.apk`.

## Как пользоваться на телефоне

1. Запустите **«Карточный Советник»**.
2. Выдайте разрешения: **«Поверх других окон»** и **«Уведомления»**.
3. Нажмите **«Запустить плавающий виджет»** и подтвердите системный запрос на запись/захват экрана (весь экран).
4. Откройте WePlay → **«Карточный магнат»**. Виджет автоматически откалибрует поле и начнёт подсвечивать лучший ход.
5. При необходимости перетащите панель в удобный угол экрана, сверните в компактную строку (`▲`) или нажмите на цвет фишки (`Авто / 🔵 / 🟠 / 🟢 / 🔴`).
